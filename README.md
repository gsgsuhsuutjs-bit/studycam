# 공부캠

소리 없이 공부하는 모습만 찍는 카메라 웹앱이에요. 폰 홈 화면에 추가해서 앱처럼 쓸 수 있어요.

- **소리 없음**: 마이크 권한을 아예 요청하지 않아요.
- **그대로 / 타임랩스**: 실시간으로 녹화하거나, 몇 초마다 한 장씩 찍어 빨리 감기 영상으로 만들어요.
- **AI 집중 분석**: 자리 비움, 딴 데 보기, 휴대폰, 앱 밖으로 나간 시간을 알아채서 끝나면 리포트를 보여줘요.
- **그림자 모드**: 내 모습을 까맣게 칠해서 몸이 안 보이게 해요. 하얀 눈도 넣을 수 있어요.
- **브이로그**: 세로 9:16 영상, 영상 끝 기록 카드, 유튜브·인스타·틱톡으로 바로 공유, 기록 카드 이미지.

AI는 모두 폰 안의 브라우저에서 돌아가요. 영상과 분석 내용은 어디에도 올라가지 않아요.

## 구조

| 경로 | 내용 |
| --- | --- |
| `index.html`, `css/app.css` | 화면 |
| `js/app.js` | 카메라, 녹화, 그림자 모드, 집중 분석, 리포트, 기록 카드 |
| `js/ai.js` | MediaPipe 모델 불러오기와 실행 |
| `lib/` | 동영상 만들기(mp4-muxer), AI 엔진(MediaPipe Tasks Vision) |
| `models/` | 사람 영역, 얼굴, 휴대폰 인식 모델 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 앱, 오프라인 실행 |

외부 라이브러리와 모델의 라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있어요.
